# Pinned host AAC-LC implementation

Code from FAAD2 is copyright (c) Nero AG, www.nero.com

The files indexed by `UPSTREAM.json` are unchanged from FAAD2 2.11.2,
revision673a22a3c7c33e96e2ff7aae7c4d2bc190dfbf92. COPYING retains the upstream
GPL-2.0-or-later license. The separate Meson build and `../db2010-aac-lc.c`
adapter are DB2010 integration code, not upstream modifications.

The build selects fixed-point LC only, without SBR, MAIN/LTP/LD/SSR, error
resilience or DRC application. The adapter currently accepts raw CPE stereo
LC/16000Hz access units matching the recovered native video setup. It validates
complete consumption, sample count, channel/profile and unsupported PCE/DRC
state. It never conceals malformed input or scans for another frame.

Only overlap, previous window shapes and PNS RNG state survive a call. A fresh
upstream handle reconstructs transient allocations and immutable transform
tables. These bounded integer fields are serialized explicitly in DB2010
checkpoints, without host pointers, native structure padding or unbounded
encoded history. Continuous upstream decoding verifies the adapter against all
601 original Demo Tour access units, plus each actually delivered subset.

Every1024-frame access unit is retained, including the initial priming unit;
FAAD2's file frontend normally suppresses that first result. This is an explicit
host-service policy rather than inferred handset gapless trimming. Existing
integer interpolation converts native16000Hz input to the48000Hz presentation
stream. Original DSP FIR/filter arithmetic and DSP ISA execution are not modeled.
